## 🎯 How to practice (the 3-pass method)

1. **Pass 1 — Open book:** read Q → try answer → check A → star the ones you fumbled.
2. **Pass 2 — Closed book (days later):** only starred questions. Any miss → back to the linked course file.
3. **Pass 3 — Out loud, timed:** 10 random files, 2 minutes per question, recorded. If you wouldn't hire you, drill again.

## 🧭 Level legend

- 🟢 **Basic** — definitions, syntax, "what is X" (0–2 yrs expected)
- 🟡 **Intermediate** — behavior, trade-offs, "what happens when" (2–4 yrs)
- 🔴 **Advanced** — internals, design, debugging, ops judgment (SDE-3+)
- 🎬 **Scenario** — live whiteboard-style problem statements
